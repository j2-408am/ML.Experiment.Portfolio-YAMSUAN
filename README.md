# Machine-Learning-Assignment-1---Yamsuan
Exercise 1: Regression Task and Exercise 2: Classification Task

Midterm project for Machine Learning. Files consist of Exercise 1: Regression Task and Exercise 2: Classification Task. Both are made through kaggle.

Exercise 1: Regression Task
- For this task, a dataset for laptop prices is used to predict prices. Though inputting numerical value was taught and used as an example in class, I have also added categorical value in this case considering that laptop brand also plays as one of the classification to predicted price.

Exercise 2: Classification Task
- For this task, a heart disease dataset is used to classify whether a patient has a heart disease or none.
